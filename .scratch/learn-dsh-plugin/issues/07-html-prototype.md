# 07 — HTML 学习页原型

Type: prototype
Status: resolved
Blocked by: 05, 06

## Question

单文件 HTML 学习页的信息架构与交互形态应该是什么样？

需要一个可打开的原型来确认：

1. 布局：左侧阶段导航 + 右侧内容区；窄屏如何折叠。
2. 阶段卡片的字段：目标、阅读材料、源码片段、练习、完成标志、预估小时。
3. 代码片段块：语法高亮（是否引入？离线单文件如何做）、文件名标签、复制按钮、行号链接。
4. 术语提示：Cordis 术语（service / fiber / inject / slot / bundle / profile / patch）的悬浮解释或术语表。
5. 进度：每阶段/每练习的勾选，localStorage 持久化，总进度条，可重置。
6. 视觉：深/浅色、字号、打印友好性（是否需要打印成 PDF）。
7. 链接策略：本机官方文档路径（`file:///E:/nodejs/...`）与仓库文件（`../../src/...`）如何组织；换机器时如何降级。
8. 内容规模控制：单文件目标大小（建议 < 500KB）、长文折叠策略。

产出：

- `docs/learn-dsh-plugin/prototype.html`（低保真即可，但可真实点击）
- 用户对布局/交互的反馈记录
- 定稿的 HTML 信息架构说明（写回本票 Answer）

**写作约定**：最终 HTML 教程正文必须调用 `humanizer-zh` 技能润色（用户 2026-11-20 要求）；原型阶段可先不润色，但定稿正文必须执行。

## Answer

用户拍板：**用变体 A（章节式）**。看完第一版后反馈「右栏太宽了，正文太窄了」——指的是页面右侧留白过多、正文列被压在 760px。已调整并复看确认。

### 用户反馈与修正

- 三选一：A。
- 初版：目录 230px、正文固定 760px、容器 `max-width: 1080px`；在 1440 宽窗口下右侧留白明显，正文偏窄。
- 修正：目录 210px、正文 `minmax(0, 1fr)` 自适应、容器 `max-width: 1320px`；目录内时长加 `white-space: nowrap`，避免被挤换行。
- 用户确认 okay。

### 定稿信息架构

1. **页面骨架**：顶部粘性工具条（品牌 + 最短/完整路径切换 + 总进度 + 深浅色 + 原型说明）+ 左侧 210px 固定目录（吸顶）+ 右侧自适应正文列。窄屏 ≤920px 时目录折叠成横向条目、正文单列。
2. **阶段区字段**（固定顺序）：阶段号与小时 → 路径标记（两条都走 / 完整路径必修）→ 练习进度 chip → 标题 → 目标 → 覆盖内容（chip 群）→ 阅读材料（列表）→ 关键代码（代码块，可选）→ 练习（卡片组）→ 自测（折叠答案）→ 完成标志。
3. **练习卡**：复选框（写进度）+ `编号 + 题目` + 折叠的「思路提示（N 条）」+ 参考位置行（`文件:行号` 用 `<code>`）+ 验收行。不给完整代码。
4. **代码块**：文件名标签 + 行号 + 复制按钮；不引第三方语法高亮（保持离线单文件、零依赖）。正文里的跳转靠 `文件:行号` 文本，不做行定位链接。
5. **术语提示**：内置 7 个术语（Cordis / fiber / inject / slot / bundle / profile / patch），正文里首次出现处加虚线下划线与 `data-tip` 悬停解释。不做独立术语表页面。
6. **进度**：练习勾选写入 `localStorage`，键 `dsh-learn:exercise-<编号>`（值 `done` / 空）；路径选择写 `dsh-learn:path`；主题写 `dsh-learn:theme`。顶部显示总进度 `已做/总数 + 百分比条`，阶段内显示 `x / y 练习`。自测题不判分、答案折叠。
7. **视觉**：CSS 变量做深/浅色两套，切换按钮在右上；打印时隐藏工具条、目录与原型切换栏，代码块 `break-inside: avoid`。
8. **链接策略**：仓库文件用相对路径 `../../src/...`；官方文档用本机绝对路径 `file:///E:/nodejs/...`，并在旁边标章节名，换机器时可降级为「按章节名在 dsh 安装目录里找」。
9. **规模**：单文件目标 < 500KB；原型 41KB，三个变体删到只剩 A 后会更小。长文默认展开，阶段 4/5 在最短路径下折叠并标「完整路径内容」。

### 三个变体的取舍（记录，供以后参考）

| 变体 | 结构 | 保留原因 |
|---|---|---|
| **A 章节式** | 左目录 + 单栏长文 | **采用**。线性通读、打印友好，最贴合「逐模块走读」的学习方式 |
| B 关卡地图 | 8 张卡片 + 右侧抽屉 | 放弃。总览强，但读长文多一次点击 |
| C 工作台 | 左列表 + 中正文 + 右练习面板 | 放弃。边读边练舒服，但每屏信息少，窄屏最吃亏 |
